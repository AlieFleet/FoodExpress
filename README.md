# shoppingsite

## Run the React app

Install [Node.js](https://nodejs.org/) if it is not already installed. From this
project folder, run:

```bash
npm install
npm run dev
```

Open the local URL printed by Vite in your browser. Do not open `index.html`
directly or use Live Server; Vite serves the React entry point and transforms
the JSX files.

To create a production build, run `npm run build`.

## Publish on GitHub Pages

The GitHub Actions workflow in `.github/workflows/deploy.yml` builds and
publishes the site whenever code is pushed to the `main` or `master` branch.
In the GitHub repository, open **Settings → Pages** and choose **GitHub
Actions** as the build and deployment source. After the workflow succeeds,
the site will be available at `https://<github-username>.github.io/<repository-name>/`.
